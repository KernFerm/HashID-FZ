# HashID FZ v1.0.2

HashID FZ contains the genuine ordered HashID signature database ported for native Flipper Zero identification, plus optional external HashID operation through a Raspberry Pi or another Linux computer over UART.

This maintenance release refreshes application/companion version metadata and is clean-built and validated for Flipper target f7/API 87.1.

Download `hashid_fz.fap` and copy it to `/ext/apps/Tools/` on the Flipper.
